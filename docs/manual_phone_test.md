## F. Expected results (print on this sheet)

- Hindi is as complete as English for every answer.
- FACT answers have ≥ 6 sentences unless the guide passages hold less.
- Family explanation is 5–8 sentences.
- The ANM message has every template line that has data; no "n/a".
- Nothing is cut mid-sentence or mid-JSON (card read, person extract, voice stock, medicine scan).
- Cloud answers are visibly fuller than offline answers.
- Targets: ≤ 3 s to first word on cloud, ≤ 15 s offline.

## G. How to read the logs if something fails

1. On the laptop run `_claude_work\run\logs.bat` (writes `app_log.txt`, phone stays untouched).
2. Search for these tags and send the matching lines back:
   - `AROGYA_BUDGET` — engine/feature/lang/tokens per generation; `capped=true` means the prompt hit the context window.
   - `AROGYA_GOLD match` — which verified item matched and its score (`strong` ≥ 0.80, `medium` 0.65–0.80).
   - `AROGYA_GOLD pin` — pinned passages + `tokens_before/after` (prompt stayed within today's size).
   - `AROGYA_GOLD skip` — a gold chunk_id missing from the installed DB (older DB; expected on v1 for new ids).
   - `AROGYA_EXTRACT_SPLIT` — long output continued/split and merged (card/person/voice/med).
   - `AROGYA_ANSWER_LEN` — sentence counts before/after the checker and salvage.
3. Also useful: `AROGYA_ROUTE` (which engine ran), `AROGYA_FORM_SAVED`, `AROGYA_CLOUD_TEST`.
